# CSV 表格整理助手

一个适合 Python 初学者阅读和扩展的小工具：检查 CSV 表格中指定列的空值和重复值，并生成结果文件。原文件不会被修改。

## 需要什么

- Python 3。程序只使用 Python 标准库，无需安装第三方库。
- UTF-8 编码的 CSV 文件，第一行必须是列名，列名不能重复或为空。

## 快速开始

打开终端，进入本项目所在文件夹，然后运行：

```bash
python table_helper.py
```

按提示依次输入 CSV 文件路径、要检查的列名，以及结果保存文件夹。例如：输入 `示例表格.csv`、`学号` 和 `结果`。程序会创建两份文件：

- `检查结果.csv`：包含所有原始数据，末尾增加“检查结果”列。
- `问题清单.csv`：只包含空值和重复值所在的数据行，以及原表格中的数据序号（不含表头）。

也可以一次提供参数：

```bash
python table_helper.py 示例表格.csv 学号 结果
```

如果系统使用 `python3` 启动 Python，请将命令中的 `python` 改成 `python3`。如果找不到 Python，请先安装并配置 Python。

## 规则与限制

- 比较时忽略单元格首尾的空白，保留原始单元格内容；大小写不同的文字视为不同值。
- 空值单独标记，不算重复；一个值出现多次时，所有对应行都标记为重复，统计数字是行数。
- 工具不会自动删除或修改数据：相同的值不一定代表应删除的记录。
- 已有同名结果文件时程序会停止，请换一个输出文件夹，避免覆盖结果。如果写入过程中出现错误，输出文件夹中可能留下不完整结果，应检查后换文件夹重试。
- 目前只处理 UTF-8 CSV，不直接读取 `.xlsx`、公式、格式或多个工作表。Excel 可另存为 UTF-8 CSV 后使用；数字、日期等数据应先检查导出结果。
- 本工具适合本地处理可信文件。使用 Excel 打开来自不可信来源的 CSV 时，单元格可能被当成公式执行，请先检查来源和内容。

## 项目结构

`table_helper.py` 是主程序，`示例表格.csv` 是练习数据，`test_table_helper.py` 是自动测试。

## 运行测试

```bash
python -m unittest -v
```
